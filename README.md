# Razal Hameed — Data Analyst Portfolio

Static portfolio (HTML + Tailwind CSS). Host free on GitHub Pages.

## Recommended GitHub repo name

```
razal-hameed-portfolio
```

Create this exact repo name (public) on GitHub, then upload the files in this folder.

After enabling Pages, your site will be:

```
https://JinnOfMaddnezz147.github.io/razal-hameed-portfolio/
```

## Before you upload

1. Add your photo:
   ```
   images/profile.jpg
   ```
   (JPG, PNG, or WebP — name it exactly `profile.jpg`)

2. Optional: replace `resume.pdf` with a newer version (keep the same filename).

---

## Host on GitHub Pages (no other service)

1. Go to https://github.com/new  
2. Repository name: **`razal-hameed-portfolio`**  
3. Public → Create repository (no README)

4. Upload **all files from this folder** to the **root** of the repo  
   (index.html, resume.pdf, images folder)

   Or from this folder in PowerShell:
   ```powershell
   git init
   git add .
   git commit -m "Razal Hameed static portfolio"
   git branch -M main
   git remote add origin https://github.com/JinnOfMaddnezz147/razal-hameed-portfolio.git
   git push -u origin main
   ```

5. Repo → **Settings** → **Pages**  
   - Source: Deploy from a branch  
   - Branch: `main`  
   - Folder: `/ (root)`  
   - Save

6. Wait 1–2 minutes, then open:  
   **https://JinnOfMaddnezz147.github.io/razal-hameed-portfolio/**
